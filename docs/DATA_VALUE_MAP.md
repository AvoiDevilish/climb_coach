## athletes ⭐🔥

Purpose:
اطلاعات پایه ورزشکار

High value fields:

⭐ age
⭐ gender
⭐ height
⭐ weight

Future usage:

- تحلیل رابطه وزن/قد با عملکرد
- دسته‌بندی ورزشکاران
- پیشنهاد برنامه تمرینی
- تغییرات بدنی

Purpose:
ارزیابی‌های عملکردی

Future usage:

🔥 مهم‌ترین منبع تحلیل پیشرفت

Possible outputs:

- نمودار رشد
- مقایسه قبل و بعد
- پیش‌بینی ضعف‌ها

- تشخیص الگوی پیشرفت
- پیشنهاد تمرین
- مقایسه با ورزشکاران مشابه
