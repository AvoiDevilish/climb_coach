# Session Design

## Session Types

### Permanent Session
- مثال: دوشنبه ساعت ۱۸ تا ۲۰
- تکرار هفتگی
- دارای weekday
- بدون تاریخ ثابت
- اعضای ثابت هفته‌ای

### Temporary Session
- فقط یک تاریخ مشخص
- بعد از پایان جلسه آرشیو می‌شود
- قابلیت مشاهده در تاریخچه


## Session Calendar

نمایش تب سانس:

- 7 روز آینده
- از امروز شروع می‌شود
- تعطیلات رسمی:
  - نمایش قرمز
  - سانس همچنان نمایش داده می‌شود
  - تصمیم تعطیلی با مربی


## Capacity Logic

Session capacity:
ظرفیت اصلی سانس

Available capacity:

capacity - active members


Makeup + Guest:
نباید از ظرفیت خالی عبور کند.


## Member Lifecycle

Permanent members:
عضو دائمی سانس

Temporary attendance:
حضور یک جلسه‌ای


## Attendance

بعد از پایان جلسه:
- ثبت حضور
- غیبت
- جبرانی
- مهمان

ولی مربی امکان ویرایش دارد.


## Future Analytics Data

Important metrics:
- تعداد حضور
- تعداد غیبت
- تعداد جبرانی
- تعداد مهمان
- پر شدن ظرفیت سانس
- تغییرات ظرفیت
- سابقه حضور ورزشکار
